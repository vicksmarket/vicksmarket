
# 📐 دليل التصميم والهندسة - فيكس ماركت (Vicks Market)

هذا الدليل مخصص للمطورين لبناء نسخة طبق الأصل من واجهة فيكس ماركت الاحترافية.

## 🎨 لوحة الألوان (Color Palette)
- **البرتقالي الأساسي (Vicks Orange):** `#FF6B00` -> يستخدم للأكشن، الأزرار الرئيسية، وسعر المنتج.
- **الأزرق (Vicks Blue):** `#00AEEF` -> يستخدم للتوثيقات القياسية والروابط.
- **الخلفية الداكنة (Deep Navy):** `#1A2332` -> لون الخلفية الأساسي في وضع الـ Dark Mode.
- **الخلفية الفاتحة (Light Gray):** `#F8F9FA` -> لون الخلفية الأساسي في وضع الـ Light Mode.
- **الأخضر (WhatsApp):** `#25D366`
- **الأزرق الداكن (Telegram):** `#0088cc`

## 📦 هندسة كارت المنتج (Product Card Architecture)
يتبع الكارت ترتيباً هندسياً ثابتاً لضمان تناسق الرفوف:
1. **هيدر التاجر (Top Bar):**
   - أيقونة دائرية مقاس `28x28px` (7 units).
   - اسم التاجر: `font-size: 11px` / `font-weight: 900`.
   - شارة التوثيق: أيقونة `16x16px`.
2. **صورة المنتج (Main Image):**
   - ارتفاع ثابت (Fixed Height): `220px`.
   - التناسب: `object-contain` لضمان عدم قص الصورة.
   - خلفية بيضاء/رمادية خفيفة لإبراز المنتج.
3. **بيانات السعر والتقييم:**
   - السعر: `font-size: 18px` / `font-weight: 900` / لون برتقالي.
   - النجوم: 5 أيقونات مقاس `12x12px` بلون أصفر ذهبي.
4. **شريط الأزرار الخمسة (Action Bar):**
   - جميع الأزرار دائرية تماماً (Full Circle).
   - القطر: `34px`.
   - الأيقونات بداخلها: `20px`.
   - الترتيب (يمين لليسار): [واتساب | تليجرام | تعليقات | تفاصيل/مساعدة | قلب المفضلة].

## 📱 نظام الاستوريز (Stories System)
- **دائرة الاستوري:** مقاس `64x64px`.
- **إطار الحالة (Status Ring):** متدرج (Gradient) من البرتقالي للوردي بسمك `2.5px`.
- **مشغل الاستوري (Viewer):**
  - شاشة كاملة (Full Screen).
  - شريط تقدم علوي (Progress Bar) مدته 5 ثوانٍ.

## 🤖 الذكاء الاصطناعي (Vicks AI)
- **الشخصية:** "فيكس" خبير مالي يتحدث باللهجة المصرية.
- **المهام:** تحليل الصور (Visual Search)، مقارنة الأسعار، والرد على استفسارات العملاء.

## ⚙️ القواعد التقنية
- **الخط الأساسي:** Cairo (Bold/Black).
- **الاتجاه:** RTL (يمين لليسار) بشكل كامل.
- **الاستجابة:** Mobile-First (مصمم خصيصاً للموبايل).
