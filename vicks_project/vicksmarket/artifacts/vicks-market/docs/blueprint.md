# **App Name**: Vicks Market

## Core Features:

- Product Display Grid: Showcase products in a responsive grid layout with images, names, prices, and seller information, similar to the provided image.
- Product Search: A prominent search bar allowing users to find products by keywords.
- Visual Search Tool: Utilize a camera input to allow users to search for products using an image.
- Category and Filter Navigation: Allow users to browse and filter products by categories such as 'Used', 'Supermarket', 'Beauty & Care', and 'Offers'.
- Product Interaction Options: Enable users to like/add to wishlist, chat with the seller, or share product listings via various messaging apps.
- User Authentication: Allow users to register and log in to manage their profiles and preferences.
- Shopping Cart: A basic shopping cart functionality to add, view, and remove products before checkout.

## Style Guidelines:

- Primary color: Vibrant Orange (#FF8A22). Chosen for its energetic and inviting quality, aligning with the commercial and engaging nature of a marketplace. It contrasts effectively with light backgrounds, ensuring visibility for interactive elements.
- Background color: Soft Off-White (#FDF8F3). A light, barely tinted off-white that creates a clean canvas for products and allows the primary orange to pop. Its subtle warmth prevents the interface from feeling sterile.
- Accent color: Deep Teal (#248E9F). This accent provides a calming and complementary contrast to the primary orange, analogous yet distinct. Its deeper tone adds visual weight to highlight important information without overwhelming the user.
- Headline and body font: 'PT Sans' (humanist sans-serif). Selected for its clean lines, legibility, and modern yet approachable feel, suitable for both short product titles and longer descriptions in a marketplace setting.
- Use clear, universally recognizable icons with a modern, filled-in or outlined style. Icons should be functional and visually integrate with the primary orange and subtle gray palette of the application, mirroring the approachable feel seen in the example.
- Implement a card-based grid layout for product displays, emphasizing clean lines, generous white space, and a visually appealing organization. Ensure the header with search, user profile, and primary navigation is sticky and always accessible.
- Incorporate subtle hover effects on interactive elements like product cards and category buttons. Utilize smooth transitions for loading states and filtering results to provide a polished user experience without distractions.
